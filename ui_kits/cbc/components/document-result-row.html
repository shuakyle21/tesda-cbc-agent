The missing state, in detail

When status = 'failed_after_retries' there is no download_url — the file does not exist. So the row shows ti-file-off, no external-link affordance, and italic text.

Two things it must not have. No retry control (there is no per-section retry API — see Re-run Action). And the explanation text is text-secondary, not text-muted: muted fails WCAG AA at 2.70, and this line is the only account of what went wrong. Greying out the one sentence that explains the failure is the wrong instinct, however much it looks “disabled.”
