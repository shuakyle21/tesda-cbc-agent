Computed, not inherited. Three findings drive real rules — see DESIGN.md §11.

Finding 1. text-muted fails AA and must never carry meaning. Anything a trainer needs to read uses text-secondary.

Finding 2. Amber base is not a text colour on the page background — icons, borders and bar fills only. Amber text always sits on amber-lt.

Finding 3. amber-lt and red-lt differ by a contrast ratio of 1.00. Badge fill alone cannot separate retried from failed — the icon and label do it.

Ruled out

Teal — forbidden
#0F6E56

CFSP-exclusive in CAMS. This app has no program dimension.

Purple — forbidden
#534AB7

NC-level-exclusive in CAMS. Nothing here compares NC levels; the code is an identifier and mono type already marks it.

Variety is not a design goal. One meaning per colour is.
